# GrokMax

GrokMax is a deterministic-first model routing and usage-efficiency CLI. The CLI lives in a pnpm workspace with internal `workspace:*` packages, so it must be bundled into a registry-ready package before install instructions become executable.

- **Version in repository:** `0.2.0-rc.2`
- **License:** MIT
- **Source:** [GitHub](https://github.com/M4G3LL4N0/grokmax)
- **Project site:** [https://grokmax.noaerth.com](https://grokmax.noaerth.com)

## Installation

The command below is the intended npm installation form; it is not evidence that this distribution has been published yet.

```sh
npm install --global @grokmax/cli
```



## First commands

```sh
grokmax --help
grokmax doctor
```
